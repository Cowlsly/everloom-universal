# Changelog

## 1.1.0 — 2026-09-14

- Promoted the uploaded v1.0.0 bundle into normal repository source files.
- Added first-class GitHub Copilot worker support.
- Added repository-level `AGENTS.md`, reusable worker-task and agent templates, Copilot prompt instructions, verification contract, and cross-agent handoff contract.

- Initial vendor-neutral Everloom release.

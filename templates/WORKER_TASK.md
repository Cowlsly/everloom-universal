# EVERLOOM WORKER TASK

## Objective
Exactly what must be achieved.

## Context
Only the information necessary to perform the task.

## Relevant files
Known starting locations.

## Constraints
What must not be changed, expanded, exposed, or destroyed.

## Acceptance criteria
Observable conditions required for completion.

## Verification
Commands, tests, checks, or evidence required before `VERIFIED` status.

## Deliverables
Expected code, files, documentation, commit, or pull request.

## Blocker behaviour
If blocked, record:
- blocker
- attempted solutions
- evidence
- safest next action

Do not hide failures or broaden the task simply to make progress look larger.

## Completion report
Return:
- Objective
- Status: IMPLEMENTED / VERIFIED / PARTIALLY VERIFIED / BLOCKED / FAILED
- Changes made
- Files changed
- Verification performed
- Exact results
- Unresolved issues
- Documentation updated
- Recommended next task

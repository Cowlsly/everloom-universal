# Everloom Adapter: Code

When the task involves software:

- inspect existing architecture before adding duplicate systems;
- preserve API compatibility unless change is intentional;
- run relevant tests, linting, type checks, builds, or smoke tests;
- inspect diffs before completion;
- record dependency changes and migration impact;
- keep secrets out of source control;
- convert failed verification into corrective ledger tasks;
- prefer release blockers over speculative refactors in completion-oriented runs.
